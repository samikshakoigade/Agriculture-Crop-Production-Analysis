# Agriculture-Crop-Production-Analysis
India's Agricultural Crop Production Analysis using Tableau (1997–2021)

## Project Overview
This project analyzes agricultural crop production in India from 1997 to 2021 using Tableau.

## Objectives
- Analyze crop production across Indian states.
- Compare different crops.
- Study seasonal crop production.
- Understand year-wise production trends.
- Identify top-performing states.

## Tools Used
- Tableau
- Microsoft Excel
- HTML and CSS (for the project website)

## Dashboard
Tableau Public: https://public.tableau.com/views/AgricultureStory_17938787189550/Story1?:showVizHome=no

## Dataset
The dataset contains agricultural information about crops, states, seasons, area and production.

## Conclusion
This project helps understand agricultural production patterns and trends in India through interactive visualizations.
